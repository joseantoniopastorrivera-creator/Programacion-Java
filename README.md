# Programación en Java - 1º DAM

Repositorio dedicado a las prácticas, ejercicios, Unidades de Trabajo (UT) y proyectos desarrollados en el lenguaje **Java** dentro del módulo de **Programación** de 1º de DAM (Desarrollo de Aplicaciones Multiplataforma).

---

## 📂 Estructura del Repositorio

El contenido se organiza de manera modular por unidades y bloques de aprendizaje:

- **`UT1-Introduccion-a-la-Programacion/`**: Algoritmia, pseudocódigo inicial y primeras estructuras de control y datos.
- *(Se irán incorporando las siguientes unidades orientadas a Programación Orientada a Objetos, estructuras estáticas/dinámicas y gestión de ficheros).*

---
